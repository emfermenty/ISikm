# Прогнозирование спроса на прокат велосипедов

## Описание

Проект посвящён построению модели машинного обучения для прогнозирования почасового спроса на прокат велосипедов. Анализируются факторы, влияющие на количество аренд: погодные условия, время суток, день недели, сезон и праздники.

## Источник данных

**Bike Sharing Dataset** — UCI Machine Learning Repository

- **URL:** https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset
- **Авторы:** Fanaee-T, H. & Gama, J. (2013)
- **Период:** 2011–2012 гг., Вашингтон (США), система Capital Bikeshare

### Файлы датасета

| Файл | Описание | Записей |
|------|----------|---------|
| `hour.csv` | Почасовые данные об аренде | 17 379 |
| `day.csv` | Дневные агрегированные данные | 731 |

### Признаки

| Признак | Описание |
|---------|----------|
| `dteday` | Дата |
| `season` | Сезон (1: весна, 2: лето, 3: осень, 4: зима) |
| `yr` | Год (0: 2011, 1: 2012) |
| `mnth` | Месяц (1–12) |
| `hr` | Час (0–23) |
| `holiday` | Праздничный день |
| `weekday` | День недели |
| `workingday` | Рабочий день |
| `weathersit` | Погодные условия (1: ясно … 4: сильный дождь) |
| `temp` | Нормализованная температура |
| `atemp` | Ощущаемая температура |
| `hum` | Влажность |
| `windspeed` | Скорость ветра |
| `casual` | Аренды незарегистрированных пользователей |
| `registered` | Аренды зарегистрированных пользователей |
| `cnt` | Общее количество аренд (целевая переменная) |

## Цель

Предсказать значение `cnt` — суммарное количество велосипедов, взятых в аренду за час — на основе временны́х и погодных признаков.
