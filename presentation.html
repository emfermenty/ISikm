Актуальность и цель

Зачем это нужно?

🚦

Проблема

В часы пик велосипедов не хватает — пользователи уходят. В остальное время парк простаивает. Операторы перераспределяют его вручную, теряя деньги и клиентов.

🎯

Цель проекта

Система аналитики, которая по времени суток, погоде и типу дня мгновенно предсказывает почасовой спрос через веб-интерфейс.

Кто использует
👤 Целевой пользователь

Диспетчер велопроката, которому нужно решить — куда подвезти велосипеды прямо сейчас.

Метод и модель

Почему Random Forest?

Сравнение на кросс-валидации (5 фолдов)
LinearRegression MAE ~109

Не улавливает двойной пик 8:00 и 17:00

Random Forest MAE ~52

В 2.2× точнее — видит нелинейные паттерны

Ключевые технические решения
✓

TimeSeriesSplit вместо KFold — тест всегда позже обучения, нет утечки данных из будущего

✓

One-hot encoding для season и weathersit — без ложного числового порядка

✓

Z-score только для непрерывных (temp, atemp, hum, windspeed) — дискретные оставлены как есть
